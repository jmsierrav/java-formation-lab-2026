# Plantilla — Anuncio de sesión en Teams

Publicar el **lunes** anterior a cada sesión (rama `week-XX-start` ya debe estar disponible).

---

## Plantilla corta (recomendada)

```
☕ Java Formation Lab 2026 — Semana XX

📅 Jueves DD/MM · 🕐 HH:MM · 1 hora
📌 Tema: <nombre de la sesión>

El código inicial ya está disponible. Si quieres, puedes empezar antes:
👉 rama: week-XX-start
👉 repo: https://github.com/robinson8406/java-formation-lab-2026
👉 reto: sessions/week-XX-<tema>/enunciado.md

No es obligatorio adelantarlo — en la sesión lo resolvemos juntos.
¿Dudas? Escribe aquí en el canal.
```

---

## Ejemplo relleno

```
☕ Java Formation Lab 2026 — Semana 03

📅 Jueves 27/08 · 🕐 4:00 PM · 1 hora
```

---

## Notas para quien publica

- Reemplaza `XX`, `DD/MM`, `HH:MM` y `<tema>` antes de enviar.
- Si es la primera sesión del participante, agrega el link a [REGLAS_DE_JUEGO.md](../REGLAS_DE_JUEGO.md) (fork + flujo de ramas).
- Recordatorio de cierre (jueves, post-sesión): publicar que ya está disponible `week-XX-solution`.
